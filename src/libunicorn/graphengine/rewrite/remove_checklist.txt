Unicorn Agent Rewrite - Old Framework Removal Checklist
=======================================================

Purpose
-------

This checklist defines the deletion boundary for the current agent framework.
It inventories the live browser runtime, backend provider runtime, integration
hooks, generated artifacts, tests, and documentation that belong to the old
architecture.

No item in this document should be removed until Phase 2 provider fixtures and
Phase 3 replacement contracts have been frozen.

Checklist labels:

- REMOVE: old implementation should be deleted
- REPLACE: old integration point should remain usable but receive a new owner
- PRESERVE: not part of the old runtime and must survive the deletion pass
- REVIEW: retain until its replacement or fixture value has been resolved
