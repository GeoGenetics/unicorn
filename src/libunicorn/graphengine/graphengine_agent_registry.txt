Unicorn Graph Engine Agent Registry
===================================

This file documents the first minimal Unicorn-native tool registry intended for
the graph engine Agent panel.

Format
------

Column 1: explicit tool call
Column 2: prose description


Tool Call                                      Description
---------------------------------------------  ---------------------------------------------
invokeTool("get_graph_context", {})            Returns the current structured Unicorn graph context captured from client-side state. This includes mode, selected datasets, active taxonomy filenames, filters, tree summary, selection, focus, report summary, and backend status.

invokeTool("list_selected_datasets", {})       Returns the currently active dataset selection and aggregate dataset summary for the current graph session.

invokeTool("get_selected_nodes", {})           Returns the nodes currently selected in the graph UI, including taxid, name, rank, direct reads, subtree reads, and visible child count.

invokeTool("get_node_details", { taxid })      Returns the detailed payload for one taxon in the current graph context. In remote server-tree mode it uses the backend tooltip endpoint. In local mode it returns a locally assembled node summary with lineage and per-dataset direct/subtree counts.

invokeTool("get_table_view", { scope, taxid, sort, limit })  Returns ranked rows for the current root scope or for one node scope. In remote server-tree mode it uses the backend table-view endpoint. In local mode it builds the rows from the active in-browser tree.

invokeTool("select_taxon", { taxid, additive })  Selects one taxon in the active graph using Unicorn's normal selection state. By default it replaces the current selection. If `additive` is true, it adds the taxon to the existing selection. Returns the resulting selected-node list.

invokeTool("focus_taxon", { taxid })           Focuses the graph on one taxon by setting it as the current focal node and centering the chart view on it. Returns a summary of the focused node.

invokeTool("center_root", {})                  Clears the current focus taxon and recenters the graph on the root of the active tree.


Notes
-----

- These tools are intentionally limited to existing graph engine capabilities.
- The registry is exposed in the browser as `window.unicornAgentRegistry`.
- The current minimal interface is:
  - `window.unicornAgentRegistry.listTools()`
  - `window.unicornAgentRegistry.invokeTool(name, args)`
- This registry remains fully client-side at this stage.
