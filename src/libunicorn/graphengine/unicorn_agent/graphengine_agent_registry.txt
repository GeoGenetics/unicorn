Unicorn Graph Engine Agent Registry
===================================

Status
------

This document describes the backend-owned read-only V1 registry.

Runtime authority:

- `unicorn_agent/registry.py`
- `unicorn_agent/tools.py`

Contract authority:

- `rewrite/contracts/provider_adapter_input.schema.json`

The browser does not define, execute, or dispatch Agent tools.


Registry Contract
-----------------

Every definition contains:

- stable dotted tool ID
- description
- when-to-use guidance
- output summary
- JSON argument schema
- implementation handler
- mutation flag

Only definitions with `mutation: false` are advertised. Registry dispatch
validates arguments before invoking a handler and rejects mutation tools unless
an explicit internal caller enables mutation.


Read-Only Tools
---------------

`graph.context`

- Use for current dataset count, visible-tree scope, selected-node count,
  minimum-read threshold, and count mode.
- Returns compact session, dataset, tree, filter, metadata, and report-state
  summaries.
- Arguments: `{}`.

`datasets.selected`

- Use when selected dataset filenames or backend count summaries are needed.
- Returns dataset count, total reads, direct taxa, and one summary per active
  dataset.
- Arguments: `{}`.

`nodes.selected`

- Use when a prompt refers to the current node selection.
- Returns selected taxids with names, ranks, direct and subtree counts, and
  visible child counts.
- Arguments: `{}`.
- Selected taxids originate in the validated browser `graph_scope`.

`nodes.find_visible`

- Use to resolve a name or unverified taxid before requesting node details.
- Returns threshold-visible matches with taxids, counts, and match type.
- Arguments:
  - required string `query`
  - optional integer `limit`, from 1 through 100

`node.details`

- Use after one or more taxids have been grounded.
- Returns identity, lineage, direct and subtree counts, visible child count,
  and per-dataset counts.
- Arguments:
  - integer `taxid`, or
  - unique integer `taxids` array with at most 100 entries

`table.view`

- Use for ranked direct or subtree rows under the root or one visible node.
- Returns the target summary and ordered table rows.
- Arguments:
  - optional `scope`: `root` or `node`
  - required integer `taxid` when scope is `node`
  - optional `sort`: `direct` or `subtree`
  - optional integer `limit`, from 1 through 1000


Backend Ownership
-----------------

Each browser turn creates a request-scoped `ReadOnlyToolService`.

The service:

- validates the complete browser request
- rebuilds context from `GraphEngineStore`
- resolves datasets and taxonomy through backend models
- applies the active `min_reads` threshold
- treats browser-selected and focused taxids only as requested scope
- verifies those taxids against the backend-visible tree
- never calls browser callbacks
- never mutates graph state

Provider adapters receive definitions and normalized results only. They never
execute Unicorn tools themselves.
